# 基于 Open-Vocabulary 的道路设施提取

本文档用于整理“基于 Open-Vocabulary 的道路设施提取”论文写作思路、实验设计和评估体系。研究目标是利用图像理解模型与彩色点云数据，实现道路设施要素的开放词汇提取、实例分割与属性估计。

## 论文写作框架

### 研究现状

#### Open-Vocabulary 方法研究现状

围绕开放词汇视觉理解与道路设施提取，重点梳理以下两类方法：

- **图像开放词汇方法**：分析 Grounding DINO、T-Rex2、SAM、Grounded SAM 等方法在开放类别检测、分割和提示词驱动识别中的能力。
- **点云开放词汇方法**：分析 OpenIns3D 等 3D 开放词汇实例分割方法在彩色点云、室外道路场景和小目标设施上的适用性。

需要重点讨论的问题：

- 现有 2D 开放词汇模型是否能稳定识别道路设施中的细粒度类别。
- 现有 3D 开放词汇模型是否适合大规模室外道路点云。
- 图像知识如何迁移到彩色点云要素提取任务中。
- 分割结果与道路设施属性估计之间如何建立关联。

#### 点云与图像语义/实例分割研究现状

围绕道路设施提取任务，需要补充传统监督式语义分割与实例分割方法的研究现状，作为 Open-Vocabulary 方法的对照基础。

重点梳理以下方向：

- **图像语义/实例分割方法**：分析 Mask R-CNN、Mask2Former、Segment Anything 等方法在道路场景图像中的目标分割能力。
- **点云语义分割方法**：分析 RandLA-Net、KPConv、MinkowskiNet 等方法在室外点云语义理解中的应用。
- **点云实例分割方法**：分析 ISBNet、SPFormer 等方法在道路设施实例分割和跨场景泛化中的表现。

需要重点讨论的问题：

- 监督式分割方法对训练数据和类别定义的依赖。
- 图像分割方法在遮挡、小目标和远距离目标上的限制。
- 点云分割方法在稀疏点云、杆状物和树木等复杂结构上的表现。
- 传统分割方法与 Open-Vocabulary 方法在类别扩展能力上的差异。

#### 数据集研究现状

数据集综述重点关注道路设施类别是否覆盖完整，尤其是俯视与侧视要素是否同时具备。

需要比较的数据集维度：

- **数据模态**：图像、点云、彩色点云、融合数据。
- **采集视角**：俯视、正视、侧视、多视角。
- **类别覆盖**：车道线、交通标志、杆状物、道路附属设施、绿化设施、公共服务设施等。
- **标注粒度**：语义分割、实例分割、检测框、属性标签。
- **道路场景复杂度**：城市道路、园区道路、交叉口、居住区道路等。

需要回答的问题：

- 现有道路数据集是否同时覆盖俯视道路标线和正视道路附属设施。
- 现有数据集是否支持 Open-Vocabulary 道路设施评估。
- 是否缺少面向道路设施开放类别提取的自采彩色点云数据集。

### 论文贡献

本文拟突出以下贡献：

1. **提出基于图像知识的彩色点云 Open-Vocabulary 道路设施提取方法**  
   结合 2D 开放词汇图像分割结果和彩色点云空间结构，实现道路设施实例提取与属性估计。

2. **构建并发布 RS30 自采道路设施数据集**  
   数据覆盖蔡家浜路、财聚路、荣欣路三个真实道路场景，包含俯视道路要素和正视道路设施要素。

### Open-Vocabulary 方法对比

#### 2D Open-Vocabulary 方法

计划对比以下方法：

- Grounded SAM 推理与集成方法：已实现，重点在财聚路和荣欣路上测试。
- Vision Banana：暂未开源，作为潜在对比方法或讨论对象。
- Qwen3-VL-Seg：暂未开源，作为潜在对比方法或讨论对象。

实验关注点：

- 不同提示词对道路设施识别结果的影响。
- 小目标、遮挡目标和长尾类别的识别稳定性。
- 2D 分割结果投影或关联到彩色点云后的实例完整性。

#### 3D Open-Vocabulary 方法

计划对比以下方法：

- OpenIns3D 推理。

实验关注点：

- 3D 开放词汇方法在室外道路设施点云上的泛化能力。
- 对杆状物、树木、围栏等结构复杂类别的识别能力。
- 与 2D 图像知识驱动方法的互补性。

### 点云实例提取方法跨场景泛化性对比

对比点云实例分割模型在跨场景设置下的泛化能力：

- 训练场景：蔡家浜路、WHU-Urban3D Training。
- 测试场景：财聚路、荣欣路。
- 对比模型：ISBNet、SPFormer。

实验关注点：

- 训练道路与测试道路变化对实例分割效果的影响。
- 通用点云实例分割模型在道路设施细粒度类别上的表现。
- 与 Open-Vocabulary 图像知识驱动方法的差异。

### 实例后处理对比与消融实验

围绕以下模块开展消融实验：

- **双通道合并**：验证俯视与正视结果融合对实例完整性的提升。
- **杆状物后处理**：验证对电线杆、路灯杆、路牌杆等细长结构的实例分离能力。
- **树木后处理**：验证对行道树树冠、树干和相邻树木实例分离的改善效果。

建议设置：

- 基线方法：不使用后处理。
- 单模块消融：分别加入双通道合并、杆状物后处理、树木后处理。
- 完整方法：使用全部后处理模块。

## 评估体系

### 实例级评价指标

采用实例级 Precision、Recall、F1-Score 作为主要指标。

- **Precision**：预测正确的实例数量 / 预测实例总数。
- **Recall**：预测正确的实例数量 / 真值实例总数。
- **F1-Score**：Precision 与 Recall 的调和平均。

实例匹配规则：

- 当预测实例与真值实例的 IoU > 0.5 时，视为正确匹配。
- 每个真值实例最多匹配一个预测实例。
- 每个预测实例最多匹配一个真值实例。

### 指标类别范围

### 真值获取方案

评估真值可采用两种方案：

1. **人工统计实例数量**  
   适用于快速验证方法召回能力，成本较低，但难以计算严格 IoU。

2. **实例分割真值标注**  
   适用于完整论文实验，可支持 Precision、Recall、F1-Score 和 IoU 匹配评估，但标注成本较高。

建议方案：

- 初期采用人工统计建立快速评估表。
- 论文核心实验选取代表性道路片段进行实例分割真值标注。
- 对关键类别和主要对比方法使用 IoU > 0.5 的实例级评价。
